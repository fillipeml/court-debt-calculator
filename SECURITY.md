# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's "Report a vulnerability" button on the repository's Security tab (private vulnerability reporting). Do not open a public issue.

You will get an acknowledgement within 72 hours and a fix or mitigation plan within 14 days for confirmed issues.

## Scope

This repository is a portfolio project. The public demo runs the extraction in simulated mode with fictional parties and a fictional case number; the only real data it ships are public monthly indices of the Brazilian central bank. It does not process real personal data. Reports about secrets or personal data accidentally committed are especially welcome and will be treated as critical.

## Supported versions

Only the `main` branch and the latest tagged release receive fixes.
