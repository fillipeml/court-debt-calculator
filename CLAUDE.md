# CLAUDE.md

Working rules for AI-assisted changes in this repository. They mirror the README; the README wins on conflict.

## Non-negotiable rules

1. **The model never does the arithmetic.** `extraction.py` returns parameters with a literal quote and a confidence; the lawyer reviews them; `debt_engine` computes. No amount, factor or percentage may be produced by a prompt.
2. **Decimal only.** Every monetary value and factor is `decimal.Decimal`; money crosses the API as decimal strings. A `float` anywhere in `debt_engine` or in a schema is a bug.
3. **Never extrapolate an index.** A month that is not in `indices/data` raises `IndexUnavailableError` and the API answers 422 with the reason. Do not add fallbacks that estimate, repeat or interpolate a month.
4. **A rule change needs a golden case.** Any change to `calculation.py`, `interest.py` or `indices.py` comes with a reference value from a public court calculator (JuriscalcWeb, Dr. Calc) or a hand-computed synthetic case, recorded in `docs/REFERENCE_CASES.md` and in `tests/engine/`.
5. **Every total is the exact sum of the displayed components** (CPC art. 524, I). Round each line, then add; never round a raw sum. The PDF, the spreadsheet and the screen read the same `as_dict()` and recompute nothing.
6. **`adjust_until` is explicit.** "The latest published month" is a choice of whoever calculates, never a default in the engine.

## Conventions

- Python 3.12, `uv`, `ruff`, `pytest`; Next.js 16 + React 19 + Tailwind 4 in `web/`, tests on Node's native type stripping.
- `src/debt_engine` is pure and offline; `src/debt_api` is the only place that reads environment variables (`CALC_API_TOKEN`, `ANTHROPIC_API_KEY`, `EXTRACTION_MODEL`, `EXTRACTION_TIMEOUT`). Without an API key the extraction runs in simulated mode with the fictional case in `demo.py`.
- Everything is English; Brazilian legal terms and index names stay in the glossary (`docs/GLOSSARY.md`). Quotes returned by the extraction stay in the document's language.
- `indices/data/*.json` is generated by `update-indices` from the central bank's public API; never edit a value by hand. A retroactive change at the source stops the ingestion (exit 2) until a human confirms it.
- Fixtures and tests hold only public index data, fictional parties and a case number dated 2099 with invalid check digits.
- Never commit `.env`, `web/.next`, `node_modules`.
- Commits: English, Conventional Commits, one logical change each, no AI attribution trailers.
